Descripción

BiblioApp permite registrar libros, socios y préstamos desde el navegador. Está pensada para bibliotecas pequeñas, como la de un instituto, donde una hoja de cálculo ya no es suficiente.

El proyecto sigue el patrón MVC1 y guarda los datos en una base de datos relacional2.

Una biblioteca organizada es una biblioteca que se usa.

Características

Instalación

Pasos para ejecutar el proyecto en local:

  1. Clonar el repositorio.
  2. Instalar las dependencias con Composer.
  3. Copiar el archivo de configuración de ejemplo.
  4. Arrancar el servidor de desarrollo.
git clone https://github.com/TU-USUARIO/biblioapp.git
cd biblioapp
composer install
cp .env.example .env
php -S localhost:8000 -t public

Para comprobar que PHP funciona se puede usar php -v en la terminal.

Ejemplo de la clase que representa un libro:

<?php

class Libro
{
    public function __construct(
        public string $titulo,
        public string $autor,
        public string $isbn
    ) {}
}

[!NOTE] La aplicación necesita PHP 8.2 o superior.

Antes de subir cambios al repositorio, ten en cuenta lo siguiente:

[!WARNING] No subas nunca el archivo .env al repositorio, contiene las contraseñas de la base de datos.

Y un consejo para producción:

[!TIP] Usa composer install --no-dev en el servidor de producción.

Preguntas frecuentes

¿Qué necesito para instalar la aplicación?
  • PHP 8.2
  • MySQL 8.0
  • Apache 2.4 con mod_rewrite
  • Composer
¿Puedo usar otra base de datos?

Sí, cualquier base de datos compatible con PDO, por ejemplo MariaDB o PostgreSQL. Solo hay que cambiar los datos de conexión en el archivo .env.

¿Cómo informo de un error?

Abre una issue en GitHub siguiendo las normas de CONTRIBUTING.md.

He elegido MIT porque es la licencia más sencilla y permisiva: cualquier persona puede usar, copiar, modificar e incluso vender el código, con la única condición de mantener el aviso de copyright. Para un proyecto educativo es ideal, porque no pone trabas a que otros aprendan de él.
